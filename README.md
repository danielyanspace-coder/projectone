# Nova Scout

**Признание, которое подтверждает делом.** Институт признания технологических (преимущественно ИИ) проектов: заявка → вердикт Экспертного совета → членство.

Сайт на Next.js 14 (App Router) + Tailwind CSS. Тёмная тема, фирменные цвета `#000000` / `#298DFF`, стиль bento box.

## Возможности

- **Дизайнерский сайт** с манифестом, миссией, описанием резидентства и процесса признания.
- **Система заявок** — форма → API → файловое хранилище → админ-панель.
- **Экспертный совет** — признание заявки генерирует резидентский ID и карточку в реестре.
- **Публичный реестр** резидентов с поиском и фильтрами.
- **Проверка подлинности по ID** (`/proverka`) + REST-эндпоинт `/api/verify`.
- **Дизайнерский сертификат с QR** (`/sertifikat/[id]`) — QR ведёт на верифицированную страницу резидента. Печать/экспорт в PDF.
- **Админ-панель** (`/admin`) — рассмотрение заявок, признание/отклонение.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка: `npm run build && npm start`.

## Конфигурация

- Контакты/ссылки/реквизиты бренда — `lib/site.ts` (плейсхолдеры email, Telegram, Instagram заменить на реальные).
- Контент (перки, критерии, совет, FAQ, блог) — `lib/content.ts`.
- Токен админки — переменная окружения `ADMIN_TOKEN` (демо-значение: `nova-admin`).

## Хранилище данных

Сейчас используется лёгкое файловое хранилище (`data/*.json`, авто-сидинг при первом запуске) — работает без внешней БД. Для продакшена слой в `lib/store.ts` готов к замене на Postgres (Supabase/Neon): достаточно переписать функции чтения/записи.

## Документы

Оферта и политика конфиденциальности — типовые шаблоны (`/oferta`, `/politika-konfidencialnosti`). Перед публикацией финализируйте с юристом и подставьте реквизиты.
